### PDF to Text converter

To run the script use the following command:

`python pdf2txt.py path/to/your/file.pdf 2 5`

where the firss argument is the path to PDF file, the second is number of the page. In case you want to convert a range of pages add the third argument(in the example it's the range 2-5)
